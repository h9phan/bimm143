Background

All functions in R have at least 3 things:

  • a name (we pick that and use it to call the function)
  • input arguments (one or more comma separated inputs that go inside the brackets when we call the function)
  • the body (the lines of the R code that do the work of the function)

Input arguments can be either required or optional. The later have fall-back default values that will be used if the user does not specify them.

Q2b. Your second version should optionally be able to return either a multi-element vector of single character nucleotides (as before) or a single character string (not a vector of single letters but a singe vector of multiple letters). For example “AAGGCTG”. [1 pt]

Functions that could be useful here are paste(), if(), cat(), return()

# generates random DNA and can return either a vector of bases or one single DNA string
generate_dna <- function(length, single.element = TRUE) {
  
  # randomly sample DNA bases
  ans <- sample(x = c("A", "C", "G", "T"),
                size = length,
                replace = TRUE)
  
  # if TRUE, combine into one string
  if (single.element) {
    return(paste(ans, collapse = ""))
  } else {
    # otherwise return as vector
    return(ans)
  }
}

# prints DNA in FASTA format
generate_dna <- function(length) {
  
  # generate random DNA bases
  ans <- sample(x = c("A", "C", "G", "T"),
                size = length,
                replace = TRUE)
  
  # combine all bases into one sequence
  dna_string <- paste(ans, collapse = "")
  
  # print FASTA header with sequence length
  cat(">len", length, "\n", sep = "")
  
  # print DNA sequence
  cat(dna_string, "\n", sep = "")

Write a generate_protein() function

Q3. Write a function generate_protein() that returns a random peptide/protein sequence of a length specified by the user. For example generate_protein(6) might return “WQRTAG”. Your function should use the single-letter code for all 20 standard amino acids and no other letters (see earlier list at the beginning of this handout) and include clear comments that explain each step of your function. [2 pts]

# This function generates a random protein sequence of the length chosen by the user
generate_protein <- function(length) {
  
  # create a vector with the 20 standard amino acid single-letter codes
  amino_acids <- c("A", "R", "N", "D", "C",
                   "Q", "E", "G", "H", "I",
                   "L", "K", "M", "F", "P",
                   "S", "T", "W", "Y", "V")
  
  # randomly sample amino acids with replacement
  protein <- sample(x = amino_acids,
                    size = length,
                    replace = TRUE)
  
  # combine the letters into one single string
  protein_string <- paste(protein, collapse = "")
  
  # return the protein sequence
  return(protein_string)
}
generate_protein(6)
[1] "NGWEQM"

Q5b. Speculate why very short random peptides are almost always found in nr, while longer ones typically are not. Your answer should refer both to the size of the sequence space (20^L for a peptide length of length L) and to the size of the known protein universe. [1 pt]

Very short random peptides are almost always found in nr while longer ones are typically not because for short peptides, many possible sequences are likely already represented somewhere in nr just by chance due to its small sequences. With longer peptides however, the number of possible sequences becomes so large that most random sequences have probably never occurred in known proteins.

Connecting your findings to immunology (MHC class II and T-cell activation)

Q6. In 3–6 sentences total and using your Q5 data and the reasoning from Q5b, what do you think this minimum length is and why might it be a bad design choice for the immune system to present very short peptides? [3 pt]

From my Q5 results, the peptides started to seem unique once they reached about 8 amino acids, so I think the minimum length for MHC class II presentation is probably around 8 amino acids or a little longer. Using very short peptides would be a poor design choice because short sequences are much more likely to also appear in the body’s own proteins, which could make it harder for T cells to tell the difference between self and foreign molecules. Once the peptides get longer, the number of possible sequences increases extremely fast (20^L), so the chance of a random foreign peptide matching something already common in the known protein universe becomes much lower. This makes slightly longer peptides much more useful for helping the immune system recognize real pathogens while avoiding unnecessary responses against self proteins.
